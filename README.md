# Excel Sales Dashboard

An interactive Excel dashboard built to analyze sales performance using 
pivot tables, key performance indicators (KPIs), and dynamic filtering 
via slicers. This project was completed as part of a structured Excel 
training program through TS Academy.

## Overview
This dashboard consolidates raw sales data into a single interactive view, 
enabling quick identification of trends, top performers, and areas requiring 
attention. It was built to demonstrate practical proficiency in Excel's 
data analysis and visualization tools.

## Key Features
- **Interactive filtering** via slicers, allowing dynamic segmentation of data 
  by category, region, or time period
- **KPI summary metrics**, including total revenue, units sold, and top-performing 
  products/regions
- **Pivot table analysis** for aggregating and summarizing large datasets
- **Conditional formulas** (SUMIF, SUMIFS) for targeted data calculations

## Technical Skills Demonstrated
- Differentiating between single-condition (SUMIF) and multi-condition (SUMIFS) 
  aggregation logic
- Structuring raw data for effective pivot table analysis
- Building slicer-driven interactivity for non-technical end users
- Applying consistent KPI design principles for at-a-glance reporting
